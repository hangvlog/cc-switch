# ClawKit Codex 一键配置

## 用户入口

应用首页首屏顶部会常驻显示“一键配置 Codex”引导卡，无论当前停留在哪个工具都能直接看到。点击“立即一键配置”会自动切换到 Codex 并进入配置流程；Codex 标题栏右侧也保留“一键配置”快捷入口。

## 使用流程

1. 输入 ClawKit 用户名、手机号或邮箱以及密码。
2. 点击“登录并一键配置”。
3. 应用自动获取当前账号可用模型、API 网关和临时凭据，并建立安全连接。
4. 页面显示“配置完成”后，点击“启动 Codex”。

手机远程连接是可选附加能力。手机没有在线时，不影响桌面端完成一键配置和启动 Codex。

## 零侵入边界

- 不覆盖官方 Codex 的配置目录或登录状态。
- 不修改官方 Codex 的应用图标、桌面快捷方式或名称。
- ClawKit 凭据仅注入由 ClawKit 启动的独立 Codex 进程，不写入渲染层、命令行参数或官方 `auth.json`。
- 停止连接或退出 ClawKit 账号后，官方 Codex 仍按原方式工作。
