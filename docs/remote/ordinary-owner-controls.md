# 普通启动的原任务控制：Desktop 3.19.57 / Mobile 0.1.42

官方 Codex 从应用目录或 Dock 普通启动后，ClawKit 现在可以通过它已有的原 owner IPC 停止指定轮次、显示并回复原任务的命令/文件/权限审批和 MCP 表单。保留启动增强路径，不重启官方进程，不启动另一个执行引擎。

停止请求每次重新发现 owner、读取快照，校验当前轮次仍在执行，再发送 version 4 `thread-follower-interrupt-turn` 并附带 `expectedTurnId`。官方 owner 会再次校验；过期轮次不会停止新轮次。只有返回的中断轮次一致才确认成功。

审批卡片附带 owner 和原始待处理请求的 SHA-256 指纹。提交前从同一 owner 重新读取请求并核对指纹；审批选项、命令规则和权限范围只取自电脑的待处理请求。发送后回读确认该请求消失；失败或结果未知不自动重发。身份认证 URL 请求仍由官方认证界面处理。现有引擎增强审批维持原协议。

普通快照和侧栏统一识别 waiting；notLoaded 表示未知，不能当作空闲/完成。等待中的异步问题继续可见。停止按钮使用真实 activeTurnId，不再把 desktop-active 占位值发给电脑。

验证覆盖：官方 26.1007.30912 / 20156，独立 CODEX_HOME/profile，直接启动官方可执行文件，无调试 pipe、无 CLI adapter。通过真实原 owner 验证旧轮次拒绝、当前轮次中断、命令审批取消、重复审批拒绝、旧指纹拒绝及 waiting 状态；本地合成模型仅产生测试输出。源文件单测覆盖相同的版本/请求绑定及手机传输选择，TypeScript 检查通过。

这些结果不等于普通启动全功能完成。精确活动分组、官方共享已读、新建任务和完整事件仍未取得普通启动等价结果。正式包安装与发布证据另见版本发布记录，真机和 iOS 未验收。
